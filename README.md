# 桌面收纳盒 · DesktopBox

C++17 + Win32 + GDI/GDI+ + Windows Shell/OLE + DWM 编写的 Windows 11 原生桌面工具，单个 EXE。

[下载 Windows 11 安装包](https://github.com/ShuLing18/Desktop-tools/releases/latest) · [性能与验证记录](OPTIMIZATION.md)

## 当前功能

- 入口是资源管理器管理的原生桌面图标，与其他桌面图标共用网格、排列、占位和系统缩放；图标字体也由 Windows 绘制。显示桌面时入口保留。入口图标仅负责启动/展开盒子，收纳内容仍是实际文件。
- 悬停只在原生图标图像范围内立即触发，图标周围空白格不触发。应用关闭后桌面入口仍存在，双击可重新运行。
- 悬停监听使用独立的原生消息线程，合并并转发鼠标通知，同时注册背景 Raw Input 后备输入。当 Windows 移除超时钩子时，原始鼠标输入继续唤醒悬停，并在输入活动时请求恢复钩子；空闲时不轮询。鼠标输入结束约 80 毫秒后另做一次位置恢复检查，覆盖 Explorer 刷新、图标移动或桌面窗口更换时鼠标已经停住的情况；正常命中仍立即展开，恢复检查完成后停止计时器。右键回调只读取主界面验证过的缓存范围，不调用窗口命中查询，也不在共享锁内查询窗口，避免监听与界面互相等待。
- 同名收纳盒已分配的桌面入口保持原文件名和位置；重新运行、刷新图标时不会重复改动带编号的入口。
- 展开面板支持毛玻璃、暗黑色、白色和跟随系统。托盘右键 →“全局设置（所有收纳盒）”统一应用图标、背景、毛玻璃透明度（0–100%）和模糊度（0–40），同时保存为新建收纳盒的默认设置。右键某个桌面收纳盒或面板空白处 →“设置（当前收纳盒）”仍可单独调整，重新运行后恢复。
- 通知区域的程序图标跟随全局 ICO；修改全局设置后立即更新，重新运行后仍按已保存的全局图标加载。单独设置某个收纳盒的图标不会改变通知区域图标。
- 设置窗口采用浅色 Fluent 风格、Segoe UI 字体、统一的圆角控件和数值区域。保留原生下拉框、滑块和按钮的鼠标、Tab、方向键、Enter/Esc 行为，按显示器 DPI 缩放。点击“确定”保存；“取消”或 Esc 撤销本次背景和图标预览。
- 同时只显示一个展开面板，悬停切换收纳盒时先立即收起旧面板，再显示新面板。鼠标离开后约 120 毫秒收起，重复离开事件不会延长等待；图标与面板之间仅保留一条狭窄的通行区域，方便移入操作，不扩大悬停展开范围。菜单、对话框、框选和拖放操作期间保留交互。支持自动、向左、向右、向上和向下展开；优先方向空间不足时选择可用的另一侧，并限制在屏幕工作区内。托盘中的展开方向统一应用于全部盒子，并保存为新建默认值；各盒子自己的菜单可单独调整方向。
- 入口拖动、网格占位和 F2 重命名由 Windows 处理；改名后同步盒子标题并保存。运行时右键桌面收纳盒入口或面板空白处可新建、重命名、删除并归还、移入及设置当前盒子。托盘使用独立的全局菜单，提供新建、全局设置、全部展开方向、登录启动、刷新全部及退出，不包含重命名、删除当前盒子或向某个盒子移入文件。其他桌面图标保持原有行为，盒子内部文件保留原生 Shell 右键菜单。
- 拖入文件、文件夹、程序或已有快捷方式时，**移动项目本体**到盒子的真实目录，不会为普通文件另建快捷方式。
- 同名项目保留两份。移动使用 Windows 文件操作接口；既有快捷方式保留参数、工作目录等信息。
- 面板内单击选中、双击打开；Ctrl 单击增减选中项，Shift 单击选择连续范围，Ctrl+A 全选。空白处可拖出半透明蓝色框，支持向任意方向框选、Ctrl 框选切换、Shift 框选追加和边缘自动滚动。选中项显示勾选标记，标题下显示选中数量。Esc 撤销正在进行的框选，或清除当前选中；再次 Esc 可关闭面板。
- 选中的文件、快捷方式和文件夹支持整组拖动。在盒子内拖动调整顺序，保持组内相对顺序；拖到桌面、其他文件夹或另一收纳盒时移动项目本体。条目右键调用 Windows Shell 原生菜单，多选后菜单作用于整组选中项。
- 顶部“排序”支持手动顺序、按修改时间（最新在前）、按名称（A–Z，数字自然排序）。排序选择按盒子保存，重新运行后恢复；切换排序时选中项仍对应原文件。自动排序后手动拖动会切换为手动顺序。
- 顶部搜索框实时按当前盒子内的文件名筛选，支持中文、不区分大小写的英文及多个空格分隔的关键词。Ctrl+F 聚焦搜索，Esc 或清除按钮恢复全部内容。搜索只改变视图，不移动或删除文件；多选、拖出和原生右键作用于显示的结果。筛选中调整顺序时保留被隐藏项目原来的相对位置。
- 排序、搜索及手动重排使用文件路径匹配前后坐标，约 220 毫秒平滑移动；新出现和退出的卡片同时淡入淡出。连续操作从当时的显示位置继续，结束后停止计时器；收起时释放临时缓冲区。遵循 Windows 的客户端动画开关，关闭系统动画时直接显示结果。
- 条目标签最多显示三行，悬停提示显示完整文件名；项目多时滚轮翻页。
- 右键的“移入文件或文件夹…”与面板“添加”使用同一个原生选择窗口。选择文件可直接点“移入”；选择文件夹或混合多选后点“移入选中项（含文件夹）”。
- 内容通过目录变更通知刷新，空闲时不轮询鼠标或目录。全部盒子的图标加载共用一个后台线程，空盒子不启动加载线程。初始化完成后后台预载每盒最多 12 个首屏图标，正在展开的盒子请求优先处理；每盒缓存最多 64 个图标。收起时保留当前可见页图标并释放其他行，取消未完成请求，重新展开时按需补载。

可调毛玻璃先绘制内容，由共享后台工作器完成全分辨率模糊，再更新当前面板；计算过程中或取样不可用时采用系统 Desktop Acrylic。最终模糊算法、取值范围和计算结果保持一致。后台最多保留一个正在计算的任务与一个最新请求，连续调节时取消旧任务，迟到结果不能恢复已收起的窗口。展开期间使用该次取样，不持续录制桌面。收起时取消任务，单份背景最多保留 500 毫秒以加快再次悬停，缓存最多 4 MiB；到期、尺寸或屏幕位置变化时释放并重新取样，大尺寸背景直接跳过短时缓存。

面板绘制重复使用当前尺寸的原生 DIB 位图，并缓存抗锯齿文字覆盖率，减少每帧创建 DC、位图和重新排版文件名的成本。文字缓存最多 48 项、192 KiB，特别大的字体只临时处理；面板位图在收起后立即释放，文字和短时背景缓存也在半秒内释放。窗口圆角和 DWM 属性只在尺寸或状态变化时更新；旧面板收起后的合成同步由一次消息完成，快速切换时仍在新取样前确认旧画面已经消失。

模糊使用按行复用的临时缓冲区，结果与原先整帧缓冲算法逐像素一致；透明度为 0 时直接绘制不透明背景，切换到纯色时立即释放毛玻璃内存。路径和配置字符串按实际长度分配，同时保留长路径和长 Unicode 配置支持。体积、内存对照结果及自查范围见 [OPTIMIZATION.md](OPTIMIZATION.md)。

## 删除收纳盒和归还原位置

每次移动前，原位置记录先写入本地；移动完成后保存实际落盘路径和 Windows 文件标识。盒子之间转移项目时保留最初来源。文件在盒子内改名后，仍能通过文件标识归还到原文件名和目录。

删除收纳盒时先逐项移回原处，全部归还成功后才移除盒子。记录在重启后仍可读取。原目录缺失时尝试重新创建，同名项目保留两份；发生占用、权限不足或取消时保留尚未归还的内容和盒子。

从外部资源管理器直接放入收纳目录的项目没有来源记录。删除时需为这些项目选择归还目录。最后一个盒子删除后，托盘仍保留，可继续新建。

Windows 自己删除桌面入口时只删除入口快捷方式，盒内内容保留；可从托盘找回。需要归还内容时，使用对应桌面收纳盒入口或面板空白处菜单中的“删除当前收纳盒并归还内容”。

## ICO 图标库

右键面板空白处 → **设置** → **选择 ICO…**，选择后在设置及面板中预览，点击“确定”应用到原生桌面入口并保存。外部 ICO 会复制到专门的 `ico` 文件夹，已有库内图标直接选用，按窗口 DPI 自适应加载。每个盒子保存自己的图标文件名，重启后重新读取；设置内也可打开图标库或恢复 Windows 文件夹图标。取消设置不改变已保存的图标，已经导入的 ICO 保留在图标库供以后选择。

托盘里的“全局设置”应用于全部现有收纳盒；之后新建的收纳盒沿用该次全局设置。单个收纳盒仍可选择自己的 ICO，其他盒子不受影响；再次确认全局设置时统一覆盖各盒子的外观。全局设置中的“恢复默认”统一恢复 Windows 文件夹图标，取消或 Esc 不提交预览。最后一个收纳盒删除后，仍可从托盘修改新建盒子的全局默认值。

## 数据和运行

运行 [build/DesktopBox.exe](build/DesktopBox.exe)。同目录存在 `portable.flag` 时启用便携模式：

- `build/ico/`：用户导入的共享 ICO 图标库。
- `build/data/settings.ini`、`build/data/items/`：默认盒子的设置和实际文件。
- `settings.ini` 中的 `DesktopLink`：对应的原生桌面入口；背景模式、透明度、模糊度也保存在本文件中。
- 根目录 `settings.ini` 中的 `NewBoxBackgroundMode`、`NewBoxGlassTransparency`、`NewBoxGlassBlur`、`NewBoxIconFile`：全局设置保存的新建默认值；每个已有盒子仍单独保存本次应用后的实际值。
- `Direction` 保存各盒子的自动/左/右/上/下展开，根目录中的 `NewBoxDirection` 保存托盘统一设置的新建默认方向；`SortMode` 保存手动/修改时间/名称排序。选择状态只在当前运行期间保留，不写入收纳文件。
- `build/data/boxes/{盒子 ID}/settings.ini`、`items/`：新增盒子的设置与实际文件。
- `build/data/origins/`：所有盒子共享的来源记录，以临时文件加原子替换方式保存。

不使用 `portable.flag` 时，默认数据目录为 `%LOCALAPPDATA%/DesktopBox`，图标库位于其中的 `ico` 子目录。可以用 `DesktopBox.exe --data-dir 路径` 指定独立开发数据目录。

盒子里保存的是真实文件，请保留整个数据目录及来源记录。旧原型已创建的快捷方式仍作为现有文件显示，不会自动移动它们指向的原文件。

## 登录后自动启动

右键 → **登录后自动启动**，使用当前用户的 Windows 计划任务：登录触发、无额外配置延迟、普通用户权限、正常进程优先级；允许电池供电，不要求空闲或联网。

任务名为 `DesktopBox-<当前用户 SID>`。启动任务与“新建”菜单分别注册，登录启动开关可随时关闭。启动任务保存数据目录参数，软件退出后配置仍然有效。

悬停监听在收纳盒初始化之前建立。原生入口启动时只读取必要的缩放度量，不为每盒枚举整张桌面；已有入口的目标、参数和图标正确时直接复用，减少磁盘写入和 Explorer 图标刷新。如果登录时桌面尚未就绪，先以约 100 毫秒间隔恢复，随后逐步降频，最长持续 60 秒；定位完成后重新检查当前鼠标并停止恢复计时器。诊断输出包含监听就绪、桌面就绪时间和恢复状态，实际登录效果仍取决于 Windows 与 Explorer 的启动进度。

Windows 不提供“所有程序中第一个启动”的排序保证；任务不设额外延迟，桌面组件在 Explorer 就绪后连接原生图标。使用普通桌面权限和正常进程优先级，以保持与 Explorer 的拖放兼容；不使用实时优先级。

## Windows 新建菜单与安装程序接口

每次正常运行 EXE 都会自动为当前用户注册 **新建 → 桌面收纳盒**，无需管理员权限和手工导入注册表。菜单图标使用全局设置的 ICO，全局恢复默认图标后菜单也同步；新增盒子继承全局外观。单个盒子修改图标不会改变全局默认值。旧版本已有的新建默认图标会在首次启动时保留。反复运行不会重复新增菜单项。

点击后通过单实例消息创建真正的新盒子，并生成 Windows 桌面入口。文件和配置仍保存到数据目录，不会留下空的占位文件。在其他文件夹的“新建”中使用该命令也会创建桌面收纳盒。

安装包可在把 EXE 放到最终安装目录后调用：

```text
DesktopBox.exe --register-shell --enable-startup
```

再以当前登录用户正常启动 EXE。安装过程中如需提权，以上当前用户注册操作应由原始登录用户执行。分享安装包使用便携模式，程序、`data` 与 `ico` 位于同一安装文件夹；请选择当前用户可写入的位置。

卸载前可以调用：

```text
DesktopBox.exe --shutdown --disable-startup --unregister-shell
```

这些接口正常完成后退出，不打开主界面；也可分别调用或附带 `--data-dir "路径"`。`--new-box` 用于系统“新建”命令，正常创建一个默认名为“桌面收纳盒”的独立盒子。注销菜单只清理本程序拥有的注册信息，旧安装目录的卸载调用不会删除新安装目录的“新建”注册。接口不会删除用户收纳内容或来源记录。

## 分享安装包

先运行 `./build.ps1 -OutputName DesktopBox-0.4.7.exe` 生成版本文件，再运行 `./package.ps1` 生成 `release/DesktopBox-0.4.7-Setup.exe`；[下载已发布的安装包](https://github.com/ShuLing18/Desktop-tools/releases/download/v0.4.7/DesktopBox-0.4.7-Setup.exe)。安装窗口允许选择安装位置，并自动在所选位置建立 `DesktopBox` 文件夹；其中的 `DesktopBox.exe`、`data/` 和 `ico/` 分别存放程序、收纳文件和用户图标。默认安装在当前用户的 LocalAppData/Programs 下，不要求管理员权限；选择其他位置时需要当前用户具有写入权限。分享包只嵌入编译后的程序，不包含本机的任何收纳文件、设置和 ICO。

安装后可通过 Windows“已安装的应用”卸载。卸载会移除程序、注册项和指向该安装的桌面入口，保留 `data/`、`ico/` 中的个人文件。更新同一安装位置会沿用这些文件。发布文件夹中的 `SHA256SUMS.txt` 用于核对下载文件；要提供公网下载链接，需把安装包上传到自己的发布平台。

## 编译和自检

需要 PowerShell。首次准备便携编译器需要 Python 3.9+：依次运行 `python tools/bootstrap_compiler.py`、`./build.ps1 -Test`、`python tools/check_binary.py`。下载固定版本 Zig 中的 C++ 编译器并校验官方 SHA-256，工具链只保存到项目目录。

也可通过 `./build.ps1 -Zig 编译器路径 -Test` 指定工具链，或使用 Visual Studio 2022+ 的 C++ 桌面开发工作负载，通过 `cmake -S . -B build-vs -A x64` 和 `cmake --build build-vs --config Release` 编译。

正式 EXE 只包含运行功能。`-Test` 会另编译 `build/DesktopBox-tests.exe`，运行与正式版相同实现的完整自检；测试夹具、图像导出、性能测量均只编入该开发用程序。CMake 可用 `-DDESKTOPBOX_BUILD_TESTS=ON` 生成此测试目标。性能对照可运行 `./tools/measure_runtime.ps1`，使用五个隔离盒子、每盒 80 个文本文件，默认测量三次；输出目录须使用新目录。

自检输出到 `build/self-test/results.txt`，涵盖四方向布局、缩放、Unicode、Ctrl/Shift 与框选、分组拖动、批量 Shell 数据和菜单、实际文件修改时间及自然名称排序、排序和方向恢复、本体移动、文件字节保持、同名冲突、快捷方式参数、文件夹内容、ICO 入库与未提交预览、原生入口生成/改名/路径大小写、设置重读、原生设置控件参数绑定与默认按钮、完整名称提示、模糊和透明度、文件改名后的来源继承、删除归还、原目录缺失和未知来源保护；磁盘条件允许时还检查跨盘移动与归还。搜索、筛选后的多选/排序保持、动画中间帧/中断/释放、桌面入口右键路由、ShellNew 注册/重复运行/卸载保护及单实例创建恢复也有自检。全局设置测试实际打开原生设置对话框，验证批量应用、单个 ICO、取消预览、统一恢复默认、新建继承及完整重启后的恢复。托盘菜单另检查全局菜单项目、排除单盒操作、全局方向与单盒方向、刷新全部，以及没有盒子时的默认设置。注册表测试使用独立的临时键，创建测试不接入真实桌面和用户菜单。自检输出框选、多选、搜索、排序动画的原生面板实际绘制图像。

任务计划测试只解析并检查 XML，不注册任务；受限会话无法连接任务服务时标记为跳过。0.4.7 实际用户会话的 [280 项自检结果](tests/reports/0.4.7/checks.txt) 和 [性能对照](OPTIMIZATION.md) 已归档到源码中。

输入可靠性自检包含后台 Raw Input 注册、没有低级钩子时的悬停通知/合并/释放后位置刷新、钩子在线恢复、并发缓存读写，以及右键对遮挡和前台变化的保护。运行 `DesktopBox.exe --diagnostics` 可请求当前实例写入数据目录的 `hover-diagnostics.txt`，记录输入计数、监听恢复次数、图标定位和菜单/对话框状态；不会打开或关闭面板。诊断请求超时后直接返回失败，不弹出阻塞对话框。

## 验收边界

真正的注销/登录启动、多显示器切换与虚拟桌面切换仍需在目标桌面验收。Win32 条目菜单使用 Windows Shell 原生完整菜单，样式由系统呈现。内存占用以当前机器实测为准。
